# Liquid Glass: Materials

This repo contains all the downloadable materials and projects associated with the [Liquid Glass](https://www.kodeco.com/ios/paths/new-ios26/48376615-liquid-glass) module from [Kodeco](https://www.kodeco.com).

--- 

Each edition has its own branch, named `versions/[VERSION]`. The default branch for this repo is for the most recent version.
